Система керування замовленнями та доставкою інтернет-магазину

Опис проєкту

Цей проєкт — реляційна база даних для керування інтернет-магазином. Вона зберігає інформацію про клієнтів, товари, замовлення, платежі, кур'єрів і доставки.

Проєкт створено для практичного закріплення навичок SQL, проєктування баз даних і роботи зі зв'язками між таблицями.

Таблиці бази даних

- "customers" — інформація про клієнтів.
- "products" — інформація про товари.
- "orders" — замовлення клієнтів.
- "order_items" — товари та їх кількість у замовленнях.
- "payments" — інформація про платежі.
- "deliveries" — інформація про доставки.
- "couriers" — інформація про кур'єрів.

Використані технології

- SQL
- SQLite
- DB Browser for SQLite
- Visual Studio Code

Реалізовані можливості

- Створення структури реляційної бази даних.
- Використання первинних і зовнішніх ключів.
- Додавання тестових даних.
- Об'єднання таблиць за допомогою "JOIN".
- Перевірка узгодженості даних.

Файли проєкту

- "design.md" — опис проєктування бази даних.
- "schema.sql" — SQL-команди для створення таблиць.
- "insert.sql" — SQL-команди для додавання даних.
- "query.sql" — SQL-запити для роботи з даними.
- "project.db" — файл бази даних SQLite.

Мета проєкту

Продемонструвати практичні навички роботи з SQL, проєктування реляційних баз даних та аналізу структурованих даних.
